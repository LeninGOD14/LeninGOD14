## 🚀 Proyectos destacados

### 🏢 Almacenes El Mueble: ERP y plataforma web en producción

Plataforma web full-stack con panel administrativo para un negocio real: sitio público, gestión de solicitudes de crédito directo, formulario de postulaciones, reportería y control de turnos.

- Formularios públicos y login protegidos con **Cloudflare Turnstile**
- Secretos y credenciales en variables de entorno, nunca en el repositorio
- Imágenes y archivos en **Cloudinary**; el servidor no guarda estado
- Usuarios desactivados en lugar de eliminados, para conservar la integridad de los datos
- Desplegado con **Docker** en **Render**

`Java 17` `Spring Boot` `PostgreSQL` `Docker` `Render` `Cloudinary` `Cloudflare Turnstile`

🔗 [Ver sitio en producción](https://almaceneselmueble.com) · 🔒 Código privado (proyecto de cliente): disponible para revisión técnica en entrevista.

### 🎭 Tradiciones: gestión de alquiler de trajes y ropa

Aplicación web para administrar el alquiler de trajes y ropa, optimizando el seguimiento financiero y los **cierres de caja diarios**.

`Java` `Spring Boot` `PostgreSQL` `Thymeleaf`

🔗 [Ver aplicación en línea](https://local-tradiciones.onrender.com) · 🔒 Código privado: disponible para revisión técnica en entrevista.
