## 🚀 Proyectos

### 🏢 Almacenes El Mueble: sitio web con catálogo + ERP interno

Una sola aplicación Spring Boot que reúne dos sistemas para un almacén real de Cayambe.

**Sitio público**
- Catálogo con buscador y filtros, y cotización directa por WhatsApp con el asesor elegido
- Directorio de asesores comerciales con reconocimientos mensuales y trimestrales
- Solicitud de crédito directo y postulaciones de empleo (con CV en PDF)
- SEO técnico: metadatos dinámicos, JSON-LD y sitemap

**Panel interno**
- **CMS:** portada, catálogo, asesores, contacto y footer se editan desde el panel
- **ERP:** asistencia del personal, transferencias de mercadería, listado de precios y agenda comercial
- Usuarios con roles (administrador y trabajador) y un permiso adicional para administrar el contenido del sitio

`Java 17` `Spring Boot` `Spring Security` `PostgreSQL` `Thymeleaf` `Docker` `Render` `Cloudinary` `Cloudflare Turnstile`

🔗 [Ver el sitio en producción](https://almaceneselmueble.com)

> [!NOTE]
> El código es privado porque pertenece a un negocio real. Con gusto lo muestro y lo explico en una entrevista técnica.
